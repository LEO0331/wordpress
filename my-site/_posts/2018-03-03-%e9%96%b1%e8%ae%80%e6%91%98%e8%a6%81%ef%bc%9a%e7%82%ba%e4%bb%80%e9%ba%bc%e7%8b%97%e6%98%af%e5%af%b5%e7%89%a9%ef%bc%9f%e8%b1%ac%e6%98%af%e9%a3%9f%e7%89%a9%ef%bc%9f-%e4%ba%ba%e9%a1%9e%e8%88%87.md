<span style="color:#000000">簡介：本書結合了科學、故事、個人經驗，詳細描寫動物與人類既愛又恨的關係。透過許多報告及著作解釋我們對待動物的不一致性，可能在前一秒鐘還很理性，但下一秒鐘轉為充滿矛盾且錯綜複雜。因此，作者認為人類對利用動物一事是抱有矛盾的想法：人類想到動物時，唯一言行相符的地方，就是言行不一。作者也認為「文化」在人類精神生活中扮演重要角色，提供我們思考人類行為背後的哲學與道德含義的依據。</span>

<span style="color:#000000">心得：雖然翻譯的素質有待加強（字太小、排版不佳）但本書於探索人和動物之間的道德倫理提出的看法是值得我們深思的。我們對動物的態度和行為比我們想像的更複雜，我們大部分已經接受內心的虛偽，然而道德觀會改變，我的獸性有時會與我做出新的妥協。人類確實對於不同種類的動物間存在偏愛與矛盾，我們如何調適這種矛盾與堅持自己的信念是需要很大意志力的。例如：吃素或是吃肉只是一種選擇，對於健康和道德的影響見仁見智，沒有吃素=健康=窈窕的說法，端看一個人能不能調和心中吃肉的慾望和不人道動物對待的道德調和。換句換說，道德問題沒有放諸四海皆準的真理，只有不斷的詰問及探討，才能得到自己的一套理論和依循法則。</span>
<p style="text-align:center"><span style="color:#003300">關於動物療法的兩三句話…</span></p>

<ul>
	<li><span style="color:#003300">動物輔助療法：用在心理健康問題者身上，大多數參與者獲益程度可被明確測量；平均改善程度與服用百解憂藥物效果相同。</span></li>
	<li><span style="color:#003300">海豚療法：難以排除海豚本身與外在美好環境或新事物所帶來的身心狀態改善（霍桑效應：改變固定作息帶來的短暫變化）此療法實際沒有太大效果，背後動機為賺錢。</span></li>
</ul>
<p style="text-align:center"><span style="color:#000000">關於動物與人的問題與可能解釋…</span></p>

<ol>
	<li><span style="color:#000000">問:人們長得像他們養的狗？</span>
<span style="color:#000000"> 可能解釋:<span style="color:#ff0000">人將寵物視為自己的延伸</span>；人們偏好某種特定長相，而這些長相出現在那些和自己相似者及對自身具吸引力的狗兒身上。原因可能為「聚合」或是「選定」理論。聚合原理：飼主與寵物經朝夕相處後會長得越來越像。</span><span style="color:#000000">選定理論：挑選寵物的當下，我們就會下意識選擇與自己相像的動物。</span>
<span style="color:#000000"> 實驗：看圖片試著配對人與狗。</span>
<span style="color:#000000"> 結果：選定理論較正確-可配對的情況只發生在純種狗身上，相處時間長短和飼主寵物間的相似度無關聯。</span>
<span style="color:#ff0000"> 結論：很多人的確有與他們寵物樣貌相似的傾向。</span></li>
	<li><span style="color:#000000">問:愛狗人士和愛貓人士間的差異？答:根據網上五大性格問卷顯示，愛狗人士和愛貓人士間的確有不同之處，然而<span style="color:#ff0000">差異不大</span>。</span></li>
	<li><span style="color:#000000">問:虐待動物的孩童變成暴力傾向的成人的關聯性？</span>
<span style="color:#000000"> 答:<span style="color:#ff0000">關聯性不大</span>，數據顯示兒童時期的虐待動物行為無法預示日後的侵略行為。</span>
<span style="color:#000000"> 可能解釋:阿魯奇認為虐待動物讓兒童可以偷偷地玩成人權力遊戲（不光彩的遊戲），也幫助強化你和共謀者間的連結。</span>
<span style="color:#000000"> 引出問題:為什麼天性善良的人會做出根本性的壞事？</span></li>
	<li><span style="color:#000000">問:為什麼寵物對某些人是好的？</span>
<span style="color:#000000"> 可能解釋:<span style="color:#ff0000">因果關係可能反過來</span>，較快樂和健康的人更傾向於養寵物。寵物鼓勵人們與其他人互動。人與動物間的連結提供社交助力，因而增進健康。</span></li>
	<li><span style="color:#000000">問:人類為何參與不道德的鬥雞活動？</span>
<span style="color:#000000">可能解釋: <span style="color:#ff0000">原理為人類架構一個建立於混合著一廂情願與邏輯思考的道德骨架。</span></span>
<span style="color:#000000">辯解：最有人性的一種活動、那不過是自然的（將公雞視為天生的鬥士）而非殘忍的、最善良人士（未曾發現鬥雞人士好的一面）、利用偉人來辯護、鬥雞建立品德、鬥雞人會善待雞。</span>
<span style="color:#000000">商用肉雞生活遠差於鬥雞：永遠見不到陽光，鬥雞有15倍的壽命及更為愉悅的生活。</span>
<span style="color:#000000">金錢與權勢造成不人道處理肉雞是合法的而鬥雞是非法的，且對鬥雞比賽加以圍剿的隱含理由是階級意識（人道組織：城市中產vs鄉下工人）</span></li>
	<li><span style="color:#000000">問:人為何被肉的味道吸引？</span>
<span style="color:#000000">可能解釋：我們是從一長排肉食動物<span style="color:#ff0000">演化</span>而來，人類轉向雜食改變的飲食習慣（多纖維植物-更多肉-農耕後回歸較多蔬果）帶來體格與頭腦上的變化，特別是人類腦力進化所產生的影響（腦容量發展成3倍）</span></li>
	<li><span style="color:#000000">問:孕婦噁心嘔吐及對肉類的排斥？</span>
<span style="color:#000000">可能解釋：因<span style="color:#ff0000">肉類對胚胎發育可能有危險</span>，所以在自然演進中發展出心理上的抵制。</span></li>
	<li><span style="color:#000000">問:文化最影響我們認為食物是屬於美味或噁心？</span>
<span style="color:#000000">可能解釋：肉食禁忌的唯一解釋是<span style="color:#ff0000">因文化傳統的反覆無常及人類習慣互相抄襲所造成的結果。</span>人類不吃他們鄙視或溺愛的動物。</span></li>
</ol>

<p style="text-align:center"><span style="color:#003300">關於如何看待動物的兩三句話…</span></p>

<ul>
	<li><span style="color:#003300">可愛在狹義的道德哲學世界中不算數，然而它對大部分人來說很重要，將影響人們對待他種生物的方式。人們偏愛如嬰兒（大眼睛、胖臉頰、柔和的線條、大額頭）樣貌的動物；害怕蛇類（人類大腦演化後在視覺上會對蛇有偵測能力、文化地區也有影響）</span>
<span style="color:#003300"> 結論：基因和環境皆會影響我們看待動物的觀念。</span></li>
	<li><span style="color:#003300">我們如何看待動物會被我們對動物的命名或形容所影響；把一個人叫成動物，也反映了我們對自身在大自然中的定位有所矛盾。</span></li>
	<li><span style="color:#003300">語言是幫助我們創造對於現實的看法，而非反映我們對於現實的觀點：我們使用肉類上的字眼幫助我們不去聯想飲食上的道德問題，且當人類面對其他較低等的動物時就不再那麼迫切需要用語義上的修飾來掩蓋良心不安。</span></li>
</ul>
<p style="text-align:center"><span style="color:#000000"><strong>人物介紹：</strong></span></p>

<ol>
	<li><span style="color:#000000">威爾森：人類天性就是喜歡與大自然親近（親生物性：不單是本能，也是一個學習規則的複雜綜合體）</span></li>
	<li><span style="color:#000000">喬安·杜那耶：某些字詞易使我們對於其他生物的剝削。</span></li>
	<li><span style="color:#000000">詹姆士：對動物的態度可分為兩個層面：情感上對動物有哪些感受（正面或負面）及效用（對人類是否有用或有益有害）</span></li>
	<li><span style="color:#000000">桑斯坦：人類對無意義報復的偏執是「懲罰性啟示」的不良延伸。</span></li>
	<li><span style="color:#000000">休模：人類的道德是基於感性而康德認為是基於理性。</span></li>
	<li><span style="color:#000000">海德特：強調在道德方面，情緒會主導理智、非邏輯的直覺系統佔有主導地位，人類認知牽涉兩種不同過程，第一種是直覺的、即時的、無知覺的及情緒化的；第二種是深思熟慮的、有意識的、合乎邏輯的及溫和的。道德的失聲：要求精確的解釋為何吃下死去的寵物是噁心的、錯誤的背後理由，人們無法做出合理的解釋。</span></li>
	<li><span style="color:#000000">羅辛：噁心為道德的情感，不同社會階級也對道德觀產生作用，上流階級較能接受「噁心因素」因為相對於這種行為是否令人生厭，這群人更強調行為是否會造成他者傷害。</span></li>
</ol>
<p style="text-align:center"><span style="color:#003300">關於人類大腦與動物的兩三句話…</span></p>

<ul>
	<li><span style="color:#003300">人類大腦對動物與物品的資訊傳輸方式不同。我們將動物分類的方式影響我們對動物的觀感，文化在社會生物學的分級上扮演重要角色。</span></li>
	<li><span style="color:#003300">電車兩難：大腦的情緒處理中樞對針對性的情況（推下某人）會有反應，而對非針對性的情況（拉下轉轍器）則無。然而最有力的道德法則是「救人優先」。                                      </span></li>
	<li><span style="color:#003300">心理框架受文化規範和認知習慣所影響，也決定我們如何看待當前的處境，我們一旦定義問題便不會考慮其他替代性的解決方法。</span></li>
	<li><span style="color:#003300">人類天生就是擬人論（為心智理論的延伸：推測他人的想法，爭取同伴、同盟和信任）者，我們把自己的慾望、感情和心理狀況投射到其他動物。擬人化是引起我們對動物有罪惡感的原因，我們常投射自己的心理狀態到別的物種。</span></li>
	<li><span style="color:#003300">寵物寬鬆的定義：與我們同住的動物，且不具特定功用。</span></li>
	<li><span style="color:#003300">伴侶動物和寵物監護人這兩種說法只是語言學上的幻覺，讓人假裝自己不擁有這些動物。</span></li>
	<li><span style="color:#003300">寵物產品熱賣：寵物被寵物工業塑造成本身就是消費者的形象，且因投射作用，許多人認為凡是自己想要的東西，他們的寵物也一樣會喜歡。</span></li>
</ul>
<p style="text-align:center"><span style="color:#000000">關於為何養寵物的問題…</span></p>

<ul>
	<li><span style="color:#000000">作者看法1：人類是唯一會僅僅為了樂趣就把其他物種長期養在自己身邊的動物。對於人以外的物種而言，不同物種間的依附行為幾乎只在非自然情況下發生。</span>
<span style="color:#000000"> 如果一項特質是由適應環境所發展而來的，那麼這項特質應該有普遍性與傳播性，如同語言是全球性的，然而養寵物卻並非如此。</span></li>
	<li><span style="color:#000000">作者看法2：人類對動物的愛來自我們親職本能的轉移，但這理論無法解釋為何不同文化的人飼養寵物的頻率和方式有那麼大的差異。</span>
<span style="color:#000000"> 養寵物像是透過人類彼此間的模仿來傳染的心理病毒（模因：文化傳遞機制，透過模仿來傳遞）</span></li>
	<li><span style="color:#000000">支持上述理論：</span>
<span style="color:#000000"> 模因必須透過學習來傳播，傾向於家庭間流通。</span>
<span style="color:#000000"> 每個社會對寵物的態度和對待方式上的差別很大。</span>
<span style="color:#000000"> 狗品種的流行和命名方式：流行的原因是因人們無意識的彼此抄襲，它是否被模仿或最終成為流行是隨機的。</span></li>
	<li><span style="color:#000000">對犬種短暫的喜愛依幂次法則（長尾理論：20%選項吸引80%注意）的統計分佈模式。</span></li>
</ul>

<p style="text-align:center"><span style="color:#003300">關於動物道德的兩三句話…</span></p>

<ol>
	<li><span style="color:#003300">貪食肉的問題：易受食用動物身上的病原體影響</span></li>
	<li><span style="color:#003300">從中立的偏好變為不道德的過程為教化，肉類的教化極其困難。</span></li>
	<li><span style="color:#003300">當我們對動物的福利有共同的關注時，我們也更渴望吃他們，因為改善了農莊動物的健康狀況使消費在他們的肉上更加的在道德上令人愉快，罪惡感減少。</span></li>
	<li><span style="color:#003300">美國人對於牛肉熱情的下滑卻異常增加補償在吃雞肉的渴望上：雞肉比牛肉更加省錢。</span></li>
	<li><span style="color:#003300">大部分素食者主要動機為健康之顧慮，而道德或環境的顧慮則緊追在後。</span>
<span style="color:#003300">全素食的飲食不能保證體重的減輕，有時反而引起飲食失調的危機。而有些有飲食失調傾向的人容易借用吃素作為她們其實有飲食問題的掩飾。</span>
<span style="color:#003300">許多素食主義者恢復吃肉的原因都是健康指數的下降，有時也因價格高或是品質好的蔬果取得困難等因素影響。</span></li>
	<li><span style="color:#003300">人類跟其他動物最直接、原始的互動便是我們需要吃掉他們的慾望；但我們也是唯一的一種動物能夠直視食物後還決定不應該吃他們。</span></li>
	<li><span style="color:#003300">動物實驗的正當理由是以較高智能生物有權對較低智能生物進行研究的假設為前提。</span></li>
	<li><span style="color:#003300">標籤化影響我們對動物的觀感：好、壞、剩餘（實驗用不到）、寵物鼠。</span></li>
	<li><span style="color:#003300">美國動物福利法：老鼠、野鼠、鳥皆不算動物，他們無法立足於法律保護之下。</span></li>
	<li><span style="color:#003300">動物關懷委員會的成員彼此間的決定有很大的差異，對待實驗動物的法案也充滿不一致性。</span>
<span style="color:#003300">動物權利倡導者懷斯以動物認知能力及行為劃分應受法定權利的等級。</span>
<span style="color:#003300">矛盾：用動物實驗證明不應該施行動物實驗。</span>
<span style="color:#003300">質疑：我們沒有足夠資料可知道大多數物種的心靈層次把他們納入應屬的道德等級。</span>
<span style="color:#003300">我們對待動物的態度通常前後不一。例如：70%人認為動物在衣物上的使用應屬動物首要權利範疇，這些人卻承認他們會穿皮製品。</span></li>
	<li><span style="color:#003300">A-B-C態度理論:</span>
<span style="color:#003300">情感：對一件事在情緒上有何感覺</span>
<span style="color:#003300">行為：態度如何影響你的外在行為</span>
<span style="color:#003300">認知：對一件事了解多少</span></li>
